The Tool Changed and Nobody Told the Agent

Silent failure and diff-conditioned recovery under tool-schema drift · SchemaDrift-120 · FROZEN 2026-09-09
Headline questions (post-CP1 reframing). Q1: when a drifted call fails, how often does it fail silently — and how often is it accepted with wrong semantics? (per drift class) Q2: does a structured machine-readable schema diff in context recover the lost success, and at what token cost vs re-injecting the full new schema or retrying on the raw error?
The deterministic minimal-pair drift taxonomy is the instrument; degradation-under-drift alone is already established (MCPEvol-Bench 2607.14642, ToolBench-X 2606.25819) and is not claimed.

Testbed

  • 30 tools · 10 domains × 3 (calendar, payments, filesystem, CRM, messaging, search, e-commerce, travel, HR, analytics); JSON-Schema function declarations; every tool carries an enum param, an optional-with-default param, an integer param, a renameable string param.
  • 120 tasks (4/tool): 90 single-step, 30 two-step; ground-truth calls checkable programmatically (canonicalized exact match + semantic checkers); two phrasings per task; frozen and git-hashed before any drift or any model call.

Five deterministic drift classes (minimal pairs: one transform per drifted schema)

ClassTransformExample
RENAMEparam renamed via synonym tablequery → search_term
ENUM-TIGHTENground-truth enum value removed/renamed"normal" ∉ {"low","standard","high"}

240 task-drift pairs (48/class); primary set = 120 (24/class) runs on every family.

Analysis

  • Paired per-task differences; bootstrap 95% CIs (10k); sign-flip permutation (20k); paired dz.
  • Recovery fraction (X−B)/(A−B) for X ∈ {diff, full schema, retry}; token cost per condition.
  • Drift-class × condition interaction tested directly; Benjamini–Hochberg over the full family; noise-floor battery (30×5 identical calls); every number traces to results/analysis.json.

Pre-registered directions (dated 2026-09-09, before any data)

  1. Newly-required arguments → largest silent-failure rate; renames most recoverable.
  2. Diff-conditioning recovers >50% of dropped success at <10% of the token cost of full-schema re-injection.
  3. Failure rates differ by model family at matched difficulty.
  4. A nontrivial fraction of drifted calls succeed with wrong semantics.
