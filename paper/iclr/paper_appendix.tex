\section{Testbed provenance and the one amendment}
\label{app:freeze}

SchemaDrift-120 was authored and frozen before any drifted episode ran. The frozen artifact is a single JSON file carrying the 30 v1 schemas, all 150 derived v2 schemas (30 tools times 5 classes), all structured diffs, the 120 tasks with both phrasings, the balanced class assignments, and the v1 and v2 ground truths; its SHA-256 hash is recorded in the project log and in the released repository (\texttt{e8bbd71c63b1...d08475}).

One amendment happened between the first freeze and the final one, during a baseline calibration pass that ran condition A only, before any drift condition had executed. Calibration on Gemini 3.6 Flash scored 114/120. The six failures were inspection-level artifacts, not capability failures: three case mismatches in free strings (fixed by making free-string comparison case-insensitive in the canonicalizer), one paraphrase invited by an unquoted reminder text, one prose phrase that leaked into an optional details field, and one ground-truth value inconsistent with its own phrasing. Three phrasings and one value were amended, the testbed re-frozen with a new hash, and all calibration and dry-run episodes discarded. No drifted arm had run at amendment time.

The 30 tools, three per domain: calendar (\texttt{create\_event}, \texttt{create\_reminder}, \texttt{book\_meeting\_room}); payments (\texttt{send\_payment}, \texttt{create\_invoice}, \texttt{refund\_payment}); filesystem (\texttt{copy\_file}, \texttt{compress\_folder}, \texttt{set\_permissions}); CRM (\texttt{create\_contact}, \texttt{log\_interaction}, \texttt{update\_deal}); messaging (\texttt{send\_message}, \texttt{schedule\_message}, \texttt{create\_channel}); web search (\texttt{web\_search}, \texttt{monitor\_keyword}, \texttt{save\_bookmark}); e-commerce (\texttt{place\_order}, \texttt{update\_listing}, \texttt{track\_shipment}); travel (\texttt{book\_flight}, \texttt{reserve\_hotel}, \texttt{hail\_ride}); HR (\texttt{request\_time\_off}, \texttt{post\_job\_opening}, \texttt{submit\_expense}); analytics (\texttt{run\_report}, \texttt{create\_dashboard\_widget}, \texttt{export\_dataset}).

\section{Verbatim prompts, diff format, and executor errors}
\label{app:prompts}

\textbf{System prompt (every condition).}
\begin{quote}\small\ttfamily
You are a tool-calling assistant. Complete the user's request by calling the provided tools with correct arguments. Use parameter defaults by omitting a parameter when the user does not specify it. Amounts, durations, and sizes must be expressed in the units the schema asks for. Call one tool at a time; after all required calls are done, reply with the single word DONE.
\end{quote}

\textbf{Condition C addendum} (appended to the system prompt; \texttt{\{diff\}} is the JSON below):
\begin{quote}\small\ttfamily
NOTE: the API behind tool '\{tool\}' was updated after the schema above was cached. Machine-readable change log for '\{tool\}' (apply it when calling):\\
\{diff\}
\end{quote}

\textbf{Diff format}, one record per changed field; the five class instantiations:
\begin{quote}\small\ttfamily
[\{"param": "memo", "change": "renamed", "old": "memo", "new": "reference"\}]\\[2pt]
[\{"param": "speed", "change": "enum\_changed", "old": "instant", "new": "realtime"\}]\\[2pt]
[\{"param": "funding\_source", "change": "now\_required", "old": \{"default": "default\_balance"\}, "new": "required, no default"\}]\\[2pt]
[\{"param": "amount\_cents", "change": "type\_changed", "old": \{"type": "integer", "desc": "Amount in cents"\}, "new": \{"type": "string", "desc": "Amount as decimal string in major units"\}\}]\\[2pt]
[\{"param": "currency", "change": "default\_changed", "old": "USD", "new": "EUR"\}]
\end{quote}

\textbf{Executor error strings} (strict profile; lenient differs only as described in \S3):
\begin{quote}\small\ttfamily
Received unknown parameter: 'location'.\\
Missing required parameter: 'calendar\_id'.\\
Invalid value 'private' for parameter 'visibility'. Allowed values: public, restricted, confidential.\\
Invalid type for parameter 'duration\_min': expected string, got integer.
\end{quote}
Documented defaults are rendered into each parameter description as ``(optional; default: X)'' so all providers see identical schema information regardless of native schema-field support.

\section{Batteries and correction detail}
\label{app:batteries}

\textbf{Noise floor.} Thirty stratified task-drift pairs, condition B strict, five identical calls each. Gemini 3.6 Flash at temperature 0: 13.3 percent of pairs flip task success at least once across the five calls, and the same share flips its ledger outcome. Qwen2.5-7B under greedy decoding: zero flips on both. Headline paired effects in this paper range from 23 to 87 points and sit far outside this floor; individual per-class cells within a few points of each other should not be over-read.

\textbf{Phrasing battery.} Conditions A and B strict re-run on phrasing 2 of all 120 tasks (Flash and Qwen). Paired shift phrasing 2 minus phrasing 1: Flash A $+0.008$ ($p{=}1.0$), Flash B strict $-0.042$ ($p{=}0.27$); Qwen $+0.008$ on both ($p{=}1.0$).

\textbf{Interaction tests.} Drift-class by condition interaction, permutation of class labels over pairs (2,000 permutations, between-class variance statistic): Gemini Flash and Pro, all three levers $p < 5\times10^{-4}$; Qwen D and E $p < 5\times10^{-4}$, C $p{=}0.37$; GPT-5.6-luna D $p < 5\times10^{-4}$, C $p{=}0.13$, E $p{=}0.19$. Where a lever does nothing overall, its per-class profile is flat, which is what the non-significant interactions say.

\textbf{Multiple comparisons.} Benjamini-Hochberg at $q{=}0.05$ over all 112 reported sign-flip tests retains 74 at an effective threshold of $p \le 0.0316$. Every effect named in the abstract survives. The GPT-5.6-luna diff decrement ($-0.033$, $p{=}0.12$) and the Qwen diff increment ($+0.042$, $p{=}0.06$) do not survive and are reported as absences of recovery, not as harms or gains.

\textbf{Token accounting.} Mean artifact size over all 150 tool-class pairs: structured diff 28.1 tokens, full v2 declaration 205.9 tokens (chars/4 estimate), ratio 0.137. Measured mean prompt tokens per call by condition ship in the released analysis output.
